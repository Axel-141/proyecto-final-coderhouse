# MateViajero - Cultura que Recorre

## Descripción

MateViajero es un sitio web dedicado a la presentación y venta de productos relacionados con el mate.

El proyecto fue desarrollado como Proyecto Final de Coderhouse, aplicando HTML5 semántico, SCSS, CSS Grid, Flexbox, Bootstrap, diseño responsive, animaciones y optimización SEO.

## Tecnologías utilizadas

* HTML5
* SCSS
* CSS3
* Bootstrap 5
* AOS (Animate On Scroll)
* Flexbox
* CSS Grid
* Git
* GitHub
* Vercel

## Páginas

El proyecto cuenta con las siguientes páginas:

* **Inicio** — presentación, productos y carousel.
* **Proyectos** — galería de proyectos mediante Cards de Bootstrap.
* **Contacto** — información y formulario de contacto.
* **Sobre Nosotros** — información sobre el proyecto.
* **Ubicaciones** — ubicación del emprendimiento.

## Responsive Design

El sitio está adaptado para diferentes tamaños de pantalla mediante:

* Diseño Mobile First.
* CSS Grid.
* Flexbox.
* Media Queries.
* Sistema de grillas responsive de Bootstrap.
* Navbar responsive con menú hamburguesa.

## SCSS

Los estilos están organizados mediante una arquitectura de partials SCSS:

* Variables.
* Mixins con parámetros.
* Nesting.
* Extend.
* Base.
* Components.
* Layout.
* Utilities.

El archivo `main.scss` se utiliza exclusivamente para importar los partials mediante `@use`.

El CSS compilado se encuentra en la carpeta `styles/`.

## Animaciones

El proyecto incluye:

* Animaciones nativas mediante `transition` y `@keyframes`.
* Animaciones mediante la librería externa AOS.

## SEO

Cada página cuenta con:

* `title` descriptivo.
* Meta description.
* Meta keywords.
* Texto alternativo (`alt`) en las imágenes.
